# Integrations

Framework integrations for `@deepfirstsearch/agent-pay`, one package per folder. Each one exposes the same safety model: the plan is sealed before the agent reads untrusted content, the policy runs outside the model, and the vault enforces the budget on-chain.

Wanted (see the [`integration`](https://github.com/DeepFirstHQ/deepfirstsearch/labels/integration) issues): MCP server, LangChain.js / LangGraph tool, Vercel AI SDK tool, Coinbase AgentKit action provider, ElizaOS plugin. Read [CONTRIBUTING.md](../CONTRIBUTING.md) first.
